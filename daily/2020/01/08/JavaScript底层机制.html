微任务与宏任务

  • 微任务: Promise, process.nextTick
  • 宏任务: 整体代码script, setTimeout, setInterval

会先于宏任务执行，微任务队列空了，才会去执行下一个宏任务

  • 作用域链与引用类型 
    var a = [1, 2, 3];
function f(a){
    a[3] = 4 // **变量是数组，是引用类型**
    a = [100] // **参数在方法内，相当于一个局部变量**
    console.log(a);// [100]
}
f(a);
console.log(a);// [1,2,3,4]

- 局部变量且失去引用：回收
